\# 🤖 NexusAI — AI-Powered Desktop Assistant



NexusAI is an AI-powered desktop assistant built with Python that combines

voice interaction, AI conversations, computer vision, system controls,

computer automation, and productivity features in one application.



\## ✨ Features



\- 🎙️ Voice-based interaction

\- 🧠 AI conversations using Google Gemini

\- 👁️ Image and vision analysis

\- 🔊 Text-to-speech responses

\- 💻 Windows system and application controls

\- 📸 Screenshot functionality

\- 🔊 System volume control

\- 🔋 Battery and system information

\- 🌐 Web and browser automation

\- 💬 WhatsApp automation

\- ⌨️ Keyboard and mouse automation

\- ⚡ Desktop productivity commands

\- 🔐 Secure environment-variable based API configuration



\## 🛠️ Tech Stack



\- Python

\- Google Gemini API

\- PySide6

\- SpeechRecognition

\- Edge-TTS

\- PyAutoGUI

\- PyGetWindow

\- PyPerClip

\- PyCaw

\- Pygame

\- Psutil

\- PyWhatKit

\- CustomTkinter

\- Pillow
